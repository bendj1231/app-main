## SECTION 1: THE VISION

### What PilotRecognition Actually Is

> **NOT a job board. A recognition and information platform.**

PilotRecognition digitizes and validates pilot reputations and logbooks. Instead of pilots "applying" for jobs and hoping, they build verified Recognition Profiles that operators across all aviation sectors can discover and pull from.

**The Core Promise:**
> "Get recognized, not just listed. Submit interest, not applications."

### The Four-Floor Tower (The Problem We Solve)

```
┌─────────────────────────────────────────────────────────────┐
│  FLOOR 3: Airline Pilots (12+ years)                        │
│  Bored. Trapped by seniority. Want change but can't.        │
│  Captain → First Officer = pay cut, position sacrifice.    │
│  Recognition Score = portable. Capabilities travel.         │
├─────────────────────────────────────────────────────────────┤
│  FLOOR 2: The Recognition Gap (THE COLLAPSE POINT)       │
│  Everyone fighting for recognition, pathways, expectations. │
│  Industry lacks communication. Pilots fly blind.          │
│  THIS IS WHERE WE PROVIDE THE FRAMEWORK.                   │
├─────────────────────────────────────────────────────────────┤
│  FLOOR 1: Flight Instructors (5,000-6,000 hrs, 15 yrs)     │
│  Stuck. Nobody leaving Floor 2. Want recognition.           │
│  Try to jump ahead → sent back. Wasted time.              │
├─────────────────────────────────────────────────────────────┤
│  FLOOR 0: Graduates (200 hrs)                              │
│  Promised airline jobs that never materialize.           │
│  Instructor line backed up 2-3 years. Batch 2015 waiting.│
│  $50,000 investment sits unused.                         │
└─────────────────────────────────────────────────────────────┘
```

**Why This Matters:** The pipeline is clogged. Not because there aren't enough pilots — because the industry has no recognition framework. Pilots don't know what operators want. Operators don't know what pilots can do. Everyone guesses.

### Pillar 2: Recognition Profile (Identity Layer)

A live, verified profile that replaces the static CV. Updates automatically.

**Recognition Score Calculation:**
```
Recognition Score =
  (Experience × 35%) +
  (Behavioral × 30%) +
  (Technical × 25%) +
  (Program Completion × 10%)
```

**Profile Components:**
- Core Identity (name, pilot ID, email)
- Flight Credentials (hours, ratings, license, medical)
- Professional Experience
- Behavioral Scores (6 competencies: SJT, psychometric, cognitive workload, stress management, decision-making, CRM)
- Technical Skills Score
- Interview Score
- Program Progress

**Verification Layer (Pillar 11 — TH2):**
- 9 background checks via Veremark: identity, license, medical, criminal, employment, education, right-to-work, references, insurance
- Blockchain-backed digital wallet (Verepass)
- Pre-cleared status for fast-track hiring
- Insurance risk profile tier (Low/Moderate/High)
