## Executive Summary

PilotRecognition is a **SaaS platform and digital education provider** for commercial aviation professionals. We sell annual subscriptions that match pilots with airline career pathways, plus digital training programs (Foundation and Transition courses). We also provide enterprise dashboard access for airlines and flight academies to access verified pilot profile data via API.

**We are NOT:** a crypto platform, a financial services provider, a job board, a travel/visa service, or a marketplace.

## What the Customer Gets (Immediate, Usable Value)

### For Pilots (B2C)
- **Upon signup (Free):** A live, text-based career profile; ability to browse public airline pathway cards; basic AI career chat.
- **Upon subscribing to Recognition Plus ($99/yr):** Full profile comparison against operator requirements; priority placement in airline search results; unlimited pathway submissions; automated medical/license renewal alerts; digital verification of credentials via third-party providers; access to exclusive private-sector pathways (charter, corporate, eVTOL).
- **Upon purchasing Foundation Program ($49):** 50 hours of logged mentorship curriculum; industry positioning modules (type rating economics, pipeline strategy); final written exam; EBT/CBTA-aligned recorded interview attached to profile.
- **Upon purchasing Transition Program ($149):** Advanced 9-competency video assessment; detailed scoring report; direct pathway eligibility preparation.

### For Airlines / Operators (B2B)
- **Free tier:** Post public pathway cards; receive pilot interest submissions; browse verified pilot directory (limited views).
- **Enterprise tier ($1,000/yr):** Full REST API access to query verified pilot database; unlimited pathway listings; EBT video interview access; placement tracking dashboard; advanced filtering by hours, ratings, medical status, location.
- **Outcome fee ($500):** Charged only when a confirmed placement occurs through a platform pathway. No placement, no fee.

## Fulfillment & Delivery Model

All products are delivered digitally through the platform:
- **Subscriptions:** Account-level feature unlocks (no license keys — tied to user account).
- **Courses:** In-app module progression, recorded video content, digital PDF certificates.
- **Verification:** Structured data outcome (verified/not verified) displayed on user profile.
- **API access:** REST API credentials issued via enterprise onboarding workflow.

No physical goods. No in-person services. No human consulting or custom work.

## Terminology Guide — PIC (Pilot Identity Credentials)

We use **PIC** (Pilot Identity Credentials) as our unified customer-facing brand for the verified digital identity system. All engineering references to wallets, tokens, and VCs are rebranded as PIC below.

| Engineering Term | Customer-Facing PIC Term |
|------------------|--------------------------|
| Wallet / Cryptographic wallet | **PIC** — Pilot Identity Credentials |
| Token / VC / Verifiable Credential | **PIC Record** — a single verified credential (license, medical, hours) |
| DID (Decentralized Identifier) | **PIC Identifier** |
| Enclave / Secure storage | **PIC Vault** — secure device storage for your records |
| Blockchain / W3C VC | Open-standard digital verification |
| Tokenize credentials | Build your PIC |
| Crypto | Cryptography (only in technical contexts) |
| Tokenized handshake / VP presentation | **PIC Export** — share a verified record with an operator |
| Wallet contents | PIC Records |

**Rule:** Never use "wallet," "token," "crypto," or "blockchain" in customer-facing copy or merchant onboarding descriptions. Use **PIC** and **PIC Record** exclusively.
