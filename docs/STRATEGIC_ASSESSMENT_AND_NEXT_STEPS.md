## The Single Next Piece to Attack

### **The Pilot Verification Flow** — where a pilot actually initiates and pays the $99.

This is the **core revenue driver and entry point**. Without it, everything else is theoretical.

### What It Needs:

| Component | Description |
|-----------|-------------|
| **Verification Dashboard** | Show Track A (Qualifications) and Track B (Flight Hours) status |
| **$99 Checkout** | Helio/Stripe integration with split logic (23% Veremark, 5% CAA, 5% Logbook, 67% Platform) |
| **ATO Selection** | Pilot names their flight school for Track B verification |
| **Consent Capture** | Explicit authorization for Veremark + CAAP-redirected directive |
| **Progress Tracking** | Real-time status: "CAAP Redirected" → "ATO Responded" → "Verified" |

### Why This First:

1. **No pilots paying = no ATO credits = no ATO subscriptions = no airlines**
2. It's the **top of the funnel** that feeds everything downstream
3. Once a pilot pays and verification completes, the ATO gets the $5 credit notification → **ATO onboarding trigger**
