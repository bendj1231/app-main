## Cluster D: Institutional & Regulatory Sources of Truth (The Sovereign IDPs)

### Node 15: FAA PRD (Federal Aviation Administration Pilot Records Database)
- **Role:** Centralized US registry
- **Validates:** Active airman certificates, enforcement histories, check-ride marks

### Node 16: EASA & National European CAAs
- **Role:** Continental and domestic aviation registries
- **Validates:** Licensing statuses across European member states

### Node 17: Regional Aviation Medical Examiners (AME registries)
- **Role:** Medical boards and clearance databases
- **Validates:** Active or deferred status of Class 1 Medical Certificates

### Node 18: Aviation Training Organisations (ATOs / Flight Schools)
- **Examples:** CAE, FlightSafety International
- **Role:** Data nodes for simulator currency and type check passes

### Node 19: National Security & Criminal Clearinghouses
- **Examples:** NBI, TSA, Interpol
- **Role:** Provide underlying data for active airport ramp and security clearances
