**Highest-priority builds for PPL students:**
1. **PPL Written Exam Prep Course + Adaptive Practice Engine** ($99 + $15/mo) — the exam portal exists but is mentorship-focused, not PPL-written-specific. This is the #1 gap.
2. **Landing Mastery Video Series** ($35) — landings are the #1 student pain point (Q31, Q33).
3. **Radio Phraseology Master Course + AI Simulator** ($39 + $15/mo) — radio fear is universal (Q21–30).
4. **Checkride Readiness Assessment** ($129) — high-margin consultation, leverages existing mentor network.
5. **PPL Progress Tracker Pro** — auto-validates logbook against requirements, generates readiness report. The logbook and Dashboard already exist; this is an enhancement.

Want me to start implementing any of these? I'd suggest beginning with the **PPL Written Exam Prep Course** page (since the exam portal infra exists and just needs PPL-specific content), or the **PPL Student Pack** bundle in the store. I can also persist this catalog to a strategy doc.
