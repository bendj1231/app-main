# Solution Catalogs — PilotRecognition.com

This directory contains 22 solution catalogs mapping pilot persona pain points to platform features, content, and revenue streams. Each catalog takes a specific pilot archetype's 100 questions and maps them to proposed solutions with category, pricing, and build status.

## Purpose

Use these catalogs to:
- **Plan features** — each catalog identifies the highest-priority builds for its persona
- **Write content** — the questions in each catalog serve as FAQ and content prompts
- **Identify gaps** — solutions marked "Gap — propose" are features the app doesn't have yet
- **Prioritize development** — catalogs with the most unaddressed pain points = highest priority
- **Price products** — each catalog includes a pricing tier structure (Free / Pack / Recognition+)
- **Map revenue** — every solution has a category (Product, Service, Community, Platform) and price

## How to Use

1. **Feature planning**: Read the relevant catalog(s) before designing a feature. The "Highest-Priority Builds" section at the end of each catalog tells you what to build first.
2. **Content writing**: Use the questions in each theme as FAQ or content prompts. Each question is a real pain point from a real pilot archetype.
3. **Gap analysis**: Solutions marked "Gap — propose" are features the app doesn't have yet. These are your roadmap.
4. **Pricing**: Each catalog includes a 3-tier pricing structure (Free / Persona Pack / Recognition+). Use these to price new features.
5. **Prioritization**: Catalogs with the most "Gap — propose" entries = highest development priority.

## Catalog Structure

Each catalog follows this structure:
- **Persona Summary** — who the pilot is, their situation, their core pain
- **Existing App Coverage** — what the app already has vs. what's missing
- **10 Themes** — each theme covers ~10 questions from the persona's 100 questions
- **Solution Tables** — each question mapped to a solution with category, price, and status
- **Cross-Cutting Solutions** — programs, services, products that span multiple themes
- **Pricing Tiers** — Free / Persona Pack / Recognition+
- **Highest-Priority Builds** — the top 6 features to build first for this persona
